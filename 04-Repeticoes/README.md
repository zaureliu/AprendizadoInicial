# Repetições

Use `for` para percorrer uma sequência e `while` para repetir enquanto uma condição for verdadeira. Ordem sugerida:

1. [contador.py](contador.py): `range` crescente e decrescente.
2. [Desafio-5.py](Desafio-5.py): tabuada histórica com `for`, preservada.
3. [soma-dos-pares.py](soma-dos-pares.py): condição dentro de um laço e soma acumulada.
4. [tabuada-while.py](tabuada-while.py): a mesma ideia da tabuada, atualizando um contador.
5. [fatorial.py](fatorial.py): multiplicação acumulada para inteiros de 0 a 20.
6. [jogo-adivinhacao.py](jogo-adivinhacao.py): até três tentativas, dicas e `break`.

O jogo usa `random`, da biblioteca padrão do Python. Digite inteiros; palpites fora de 1 a 10 também gastam uma tentativa. Nos laços, observe o que faz a repetição terminar.

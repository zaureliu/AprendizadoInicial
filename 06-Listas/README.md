# Listas

Uma lista guarda vários valores. Vamos usar `[]`, `append`, índices, `len` e laços para trabalhar com esses valores:

1. [media-de-valores.py](media-de-valores.py): guardar cinco números e calcular a média.
2. [maior-e-menor.py](maior-e-menor.py): comparar cinco valores a partir do primeiro item.
3. [pares-e-impares.py](pares-e-impares.py): distribuir cinco inteiros entre duas listas.
4. [lista-de-compras.py](lista-de-compras.py): adicionar produtos até digitar `fim`; entradas vazias não entram na lista.

Experimente números repetidos, negativos e zero. A lista de compras existe apenas durante a execução; não é gravada em arquivo.

# Fundamentos

Primeiros contatos com `input()`, `print()`, variáveis, conversões com `int()`/`float()` e operações matemáticas. Ordem sugerida:

1. [Obter-dados-user.py](Obter-dados-user.py) e [olá-mundo1.py](olá-mundo1.py): receber dados e mostrá-los na tela. Use dados fictícios.
2. [soma.py](soma.py) e [Soma-numeros.py](Soma-numeros.py): duas versões históricas da soma de inteiros.
3. [Operacoes-aritmeticas.py](Operacoes-aritmeticas.py): operadores e precedência; use um segundo número diferente de zero.
4. [Operacoes-aritmeticas2.py](Operacoes-aritmeticas2.py): antecessor e sucessor.
5. [conversao-temperatura.py](conversao-temperatura.py): Celsius para Fahrenheit.
6. [conversao-velocidade.py](conversao-velocidade.py): km/h para m/s.
7. [conversao-tempo.py](conversao-tempo.py): horas, minutos e segundos usando `//` e `%`.

Os seis arquivos históricos conservam seus nomes. Nos três novos, observe como uma fórmula transforma a entrada em outro valor. Use números válidos e respeite os intervalos pedidos; a validação virá nas próximas áreas.

# Primeiros projetos

Pequenos programas de terminal para reunir os conceitos anteriores, sem instalações extras:

1. [calculadora-terminal.py](calculadora-terminal.py): menu com quatro operações, funções, repetição de entrada inválida e verificação de divisão por zero.
2. [mini-cadastro.py](mini-cadastro.py): menu para cadastrar e listar nomes fictícios em uma lista. Os dados somem ao encerrar.
3. [analisador-ip.py](analisador-ip.py): função que verifica quatro partes numéricas de 0 a 255, separadas por pontos, sem zeros à esquerda.

Use a opção `0` para sair dos menus. O analisador de IPv4 trabalha somente com texto: não faz ping, não consulta serviços e não verifica se um endereço está em uso. Não é necessário fornecer dados pessoais em nenhum projeto.

# Strings

Depois dos métodos básicos do Desafio 01 e dos laços, pratique percorrer e comparar textos:

1. [contar-vogais.py](contar-vogais.py): `lower`, busca de caracteres e contador, incluindo vogais acentuadas.
2. [palindromo.py](palindromo.py): inverter texto com um laço; ignora maiúsculas e espaços comuns, mantendo os acentos. Digite sem pontuação.
3. [analisar-nome.py](analisar-nome.py): `strip`, `upper`, quantidade de palavras e primeira/última palavra.
4. [procurar-palavra.py](procurar-palavra.py): buscar uma palavra inteira, sem diferenciar maiúsculas, em uma frase sem pontuação.

`split()` devolve uma lista de palavras. Aqui vemos apenas a separação e o acesso às palavras; na próxima área vamos criar e preencher nossas próprias listas. Use nomes fictícios.
